# Klasifikasi Resep Kuliner Indonesia Berdasarkan Bahan Menggunakan Machine Learning

Proyek ini dibuat untuk memenuhi tugas mata kuliah *Machine Learning*. Tujuannya adalah membangun model klasifikasi untuk memprediksi apakah sebuah resep masakan Indonesia masuk dalam kategori **Populer (1)** atau **Biasa (0)** berdasarkan analisis bahan masakan (*ingredients*).

---

## Struktur Proyek & Dataset
- **Dataset:** `Indonesian_Food_Recipes.csv` (berisi 14.945 baris data resep kuliner dengan 8 kategori utama).
- **File Utama:** `tugas_ml.ipynb` (Jupyter Notebook yang berisi seluruh tahapan dari awal hingga evaluasi).
